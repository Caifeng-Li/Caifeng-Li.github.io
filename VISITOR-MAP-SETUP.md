# Visitor map

The StatFlag visitor map for https://caifeng-li.github.io/ is already connected. The map is embedded from https://statflag.com/m/6b7eb3b1c05612121a8ad534 and will display visitor statistics reported by StatFlag.

Upload the files in this folder to the root of the `Caifeng-Li.github.io` GitHub repository to publish the site. The map depends on StatFlag being reachable and allowing embeds on the configured domain.
